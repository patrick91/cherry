Features

Built for how you actually work.

01

One rail for everything

Agents, terminals, and your project's dev commands live in a single left rail. Jump between them with a click or ⌘1–⌘9.

02

Renders only what you see

An AppKit-backed canvas draws just the visible rows, so 50,000 lines of scrollback stay buttery while you scroll.

03

Real login shells

Every tab owns a live PTY-backed shell with your full environment — not a sandboxed imitation of one.

04

Agents drive the terminal

A built-in MCP bridge gives Claude and Codex process-first tools to open terminals, read output, and wait on ports.

05

Notes & todos, built in

Keep scratch notes and a todo list beside your sessions — both readable and writable over the same MCP bridge.

06

Native to the Mac

SwiftUI window chrome, a traffic-light tab rail, and real macOS keyboard shortcuts. It feels like home, not a web tab.

MCP control

Hand your agents the keys.

Cherry ships a stdio MCP helper alongside the app. Register it once and every agent gets process-first tools — spawn shells, read output, wait for a port, and manage notes and todos.

  • terminals
  • agents
  • output
  • ports
  • notes
  • todos
register the helper 
# point your harness at Cherry's MCP helper
$ claude mcp add --transport stdio --scope user \
    cherry -- Cherry.app/Contents/MacOS/CherryMCP

✓ added MCP server "cherry"
